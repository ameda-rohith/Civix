# Civix Screenshots Directory

Place your application screenshot PNG files in this directory using the following file names:

- `01_citizen_dashboard.png` (Citizen Dashboard & Pincode Locality Feed)
- `02_official_dashboard.png` (Officials Administrative Dashboard & 5-Stage Status Filters)
- `03_governance_response.png` (Official Response & Inspector Notes Modal)
- `04_polls_sentiment.png` (Public Opinion Surveys & Live Sentiment Graphs)
- `05_reports_export.png` (Monthly Reports Dashboard & Export CSV / PDF Buttons)

Once added, commit and push them to GitHub, and they will automatically render inside the main `README.md` page!
